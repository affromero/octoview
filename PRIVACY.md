# Privacy Policy

**octoview does not collect, store, transmit, or share any personal data.**

- No analytics, no telemetry, no accounts, no tracking, no advertising, no
  cookies of its own.
- The extension runs entirely in your browser. It fetches only the file you
  choose to preview, from GitHub (`github.com`, `raw.githubusercontent.com`,
  `media.githubusercontent.com`), using your existing GitHub session. It makes no
  request to any other server, ever.
- Nothing about the files you view, or your activity, is sent anywhere. The only
  network request octoview makes is the request to GitHub for the file you asked
  to preview — the same request your browser already makes when you open that
  page.
- Untrusted file content (HTML reports, notebook outputs) is rendered inside a
  sandboxed frame with no network access and no access to your GitHub session.

Because octoview collects no data, there is nothing to access, correct, or
delete, and no third parties receive any information.
